How Priority Queue Works:

Users with higher priority (VIP, more bookings) are served first. This uses a Max Heap data structure where the root is always the highest priority element.

Max Heap Properties:

• Parent node always ≥ children
• Root is maximum element
• Insert: O(log n) time
• Extract Max: O(log n) time
• Used for priority queues!
